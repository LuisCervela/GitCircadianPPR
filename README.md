# GitCircadianPPR

Pipeline to identify rhythmic PPR genes (and core clock controls) across multiple *Arabidopsis thaliana* photoperiod datasets using a multi-method consensus approach (RAIN, COSINOR, JTK/MetaCycle), plus promoter motif scanning, peak-time visualization, and optional SUBA5 subcellular localization summaries.

## Folder structure

- `scripts/` – analysis pipeline scripts (run in order)
- `data_raw/` – raw inputs (some not tracked on GitHub; see below)
- `data_clean/` – curated inputs (gene lists) + derived intermediate tables (some ignored; see `.gitignore`)
- `tables/` – analysis outputs (key results committed)
- `figures/` – plots (not committed)

## Optional input data (recommended for localization summaries)

### SUBA5 localization export (recommended)
- `data_raw/suba_locations.xlsx`

Full SUBA5 export for the working gene universe (PPRs + clock controls). This enables:
- cleaning to a simple `AGI + location_consensus` table (Script 00a)
- UpSet visualization of localization memberships (Script 00b)
- per-photoperiod phase-bin × localization count tables for TRUE PPR oscillators (Script 00c)

The cleaned derivative (`data_clean/suba_location_consensus_clean.*`) is regenerated and ignored by default.

## Promoter sequences (how they were generated)

Promoter sequences were retrieved using RSAT::Plants `retrieve-seq` from the **TRUE PPR oscillator lists per photoperiod** (robust + candidate) and then scanned for short consensus motifs.

Steps used:
1. Take the TRUE PPR list for each photoperiod (AGI codes).
2. Paste the AGI list into RSAT::Plants `retrieve-seq`:
   - URL: https://rsat.eead.csic.es/plants/retrieve-seq_form.cgi
3. Settings:
   - Organism: `Arabidopsis_thaliana.TAIR10.60`
   - Feature type: `gene`
   - Sequence type: `upstream`
   - Limits: from `1` to `1000`
   - “noorf” checked
4. Download/save the resulting sequences as:
   - `data_raw/rsat/12L12D_promoters.txt`
   - `data_raw/rsat/12L12D_LL_promoters.txt`
   - `data_raw/rsat/16L8D_promoters.txt`
   - `data_raw/rsat/8L16D_promoters.txt`

Note: these RSAT exports are **not required** for rhythmicity calling; they are only required for the motif scan (Script 06). By default, `data_raw/rsat/` is ignored by `.gitignore`.

## Pipeline (run order)

1. `scripts/01_prepare_mbqn_data.R`  
   Reads the raw MBQN file, keeps selected GEAR datasets, and splits into photoperiod-specific tables.

2. `scripts/02_subset_PPRclock.R`  
   Subsets each photoperiod table to the PPR+clock gene list and writes PPR-only/clock-only gene lists.

3. `scripts/03_load_PPRclock_all_conditions.R`  
   Loads per-condition tables and builds expression matrices + annotations in memory (`expr_*`, `annot_*`).

4. `scripts/04_multimethod_consensus.R`  
   Multi-method rhythmicity calling and consensus classification (robust vs candidate) per gene and photoperiod.  
   Outputs `tables/final_consensus_table.csv` and supporting tables.

5. `scripts/05_List_of_candidates.R`  
   Exports per-photoperiod oscillator lists for PPR genes, labeled as robust vs candidate:
   - `tables/PPR_oscillators_12L12D.csv`
   - `tables/PPR_oscillators_12L12D_LL.csv`
   - `tables/PPR_oscillators_16L8D.csv`
   - `tables/PPR_oscillators_8L16D.csv`

6. `scripts/06_Circadian_motif_scan.R`  
   Scans promoter sequences for short consensus motifs (both strands), writing:
   - `tables/motif_scan_per_photoperiod/motif_counts_<condition>.csv`

7. `scripts/07_Radar_plot_TRUE_PPR.R`  
   Generates peak-time radar plots for TRUE PPR oscillators (robust+candidates) and saves PNG files in `figures/`.  
   Note: `figures/` is not committed to the repo.

8. `scripts/08_plot_gene_by_condition.R`  
   Utility plotting for individual genes across datasets/photoperiods (raw + normalized overlays).

9. `scripts/09_Top10_robust_PPR_priority.R`  
   Ranks robust rhythmic PPR genes using a composite score integrating rhythmicity strength, robustness across photoperiods,
   phase consistency, and promoter motif evidence.  
   Outputs:
   - `tables/PPR_priority_ranking.csv`
   - `tables/Top10_robust_PPRs.csv`

### Optional downstream: SUBA5 localization summaries
- `scripts/00a_clean_SUBA_locations.R`  
  Cleans `data_raw/suba_locations.xlsx` to `data_clean/suba_location_consensus_clean.*` (AGI + location consensus).

- `scripts/00b_Plot_SUBA_locations.R`  
  Bins locations (mitochondrion/chloroplast/nucleus/cytosol/other) and generates an UpSet plot.

- `scripts/00c_SUBA_locations_per_time_of_the_day.R`  
  Combines TRUE PPR oscillators (from `tables/final_consensus_table.csv`, filtered to `data_clean/PPR_only_genelist.txt`)
  with SUBA bins and outputs phase-bin × localization count tables per photoperiod:
  - `tables/TRUE_PPR_phasebin4h_loc4_by_condition.xlsx`
  - `tables/TRUE_PPR_phasebin4h_loc4_<condition>.csv` (optional)
