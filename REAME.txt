# Circadian PPRs Project (TFM Bioinformática)

Analysis of PPR and core clock genes across Arabidopsis circadian datasets
using GEAR MBQN expression matrices, RAIN rhythmicity analysis, and clustering.

Scripts:
- 01_...     preprocessing
- 02_...     gene selection
- 03_...     load expression
- 04_...     plotting
- 05_...     rhythmicity with RAIN

Data:
Data coming from the GEAR databse. For experiments selected check Conditions.xls
- data_raw: original MBQN + metadata
- data_clean: trimmed matrices + PPRclock subsets
